# TWO — Rayon Jardin 2027

Application TWO Mobile Loupe Interactive, compatible ordinateur et mobile.

## Utilisation

Ouvrir le site GitHub Pages puis choisir « Lancer le diaporama » ou « Mode édition ».
Déplacer la loupe sur le plan pour afficher les zones et leurs fiches avant/après.
Le plan et les visuels de départ sont intégrés dans index.html.

## Sauvegardes

Les modifications du mode édition sont conservées dans le navigateur de chaque appareil.
Utiliser Édition → Sauvegarde → Exporter pour sauvegarder le projet en JSON, puis Importer sur un autre appareil.
Ces modifications locales ne sont pas envoyées automatiquement à GitHub.

## Publication

GitHub Pages publie la racine de la branche main. Chaque modification enregistrée dans cette branche déclenche une nouvelle publication.
